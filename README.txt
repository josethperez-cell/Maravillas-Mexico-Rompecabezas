# Maravillas de México: Rompecabezas Maestro

Un juego de rompecabezas interactivo desarrollado en **Java** que muestra algunas de las maravillas de México.

## Características principales
- **10 Niveles únicos: Con datos históricos y curiosidades de cada sitio.
- **Sistema de Logros: 9 trofeos desbloqueables basados en desempeño.
- **Modos de Dificultad: Desde 3x3 hasta el modo **(!) HARDCORE** con tiempo límite.
- **Interfaz Fluida: Uso de `CardLayout` para una experiencia sin ventanas emergentes.
- **Ranking Global: Persistencia de datos para guardar los mejores puntajes.

## Tecnologías utilizadas
- Java SE (JDK 17+)
- Swing & AWT (Interfaz Gráfica)
- File I/O (Persistencia de datos)
